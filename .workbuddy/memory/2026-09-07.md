- 串口屏只能选 UART5(PC12/PD2)，USART6 与 PC12 无关，文档该备选项有误。

## 2026-09-09 USART1 串口失败根因（针对 ioc 配置）

新依据：野火骄阳电机开发板硬件规格书（`res/[野火]STM32F407_骄阳电机开发板硬件规格书.pdf`）。

- 板上 CH340 通过 J6/J7 跳线帽连到 **PB6/PB7**（USART1 复用映射），**不是** PA9/PA10。当前 ioc 配的是默认映射 PA9/PA10，板上根本没走到 CH340 → 完全无输出。
- 必须同时改：ioc 把 USART1 改到 PB6/PB7 + USART1_REMAP（CubeMX 会自动加 AFIO remap）；板上的 J6/J7 跳线帽必须装上（规格书 §2.5.1 ②）。
- 板上**没有**板载 ST-Link/调试器，CLAUDE.md 那条写错。烧录需外接 SWD 调试器到 1×5P XH2.54 座。板上两个 Type-C：一个是 USB 转串口（CH340）、一个是 USB Device（STM32 内置 USB，PA11/PA12）。
- 代码：main.c USER CODE 1 的 printf 在 HAL_Init() 之前调用，huart1 未初始化，"Init Complete" 这行永远不输出（但 Boot OK 在初始化之后会正常）。
- 已排查并排除：HSE 25MHz、PLL 168MHz、APB2 84MHz、波特率 115200、NVIC Group2、USART1 抢占 3/0、TIM2 时基、MicroLIB、printf 重定向、编译 0 错误 0 警告——全都对。
- 报告：`Docs/usart1_diagnostic.md`
